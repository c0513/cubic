Как играть 🎮

На iPad: нажми «Написать код», введи Python и запускай. Команды двигают Данчезавра по клеткам настоящей карты. Поворот камеры: проведи пальцем по 3D-миру.

На компьютере: тоже управляй с помощью Python. Мышью можно только поворачивать камеру.

Python: открой миссию, напиши команды в редакторе, запусти код и посмотри, что сделал герой. Отступы после for и if важны!
